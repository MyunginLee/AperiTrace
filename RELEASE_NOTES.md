# AperiTrace 0.1.0

- Exact five-integer lattice identities across physical/internal projections.
- Linear-path membership intervals, event-resolved finite diffraction, and
  explicit floating-point boundary-sensitivity status.
- Self-contained linked state exports and independent direct recomputation.
- Runnable changed-path recovery and targeted-resampling example.
- Retained paper data and executable figure/table reproduction.
- Optional Windows/Quest 3 app with guided examples, inspection, view tools,
  adaptive grids, colormaps, local sessions, screenshots and numerical export.
- Controller and tracked-hand interaction, pause safety and guarded quit.

## Scope and limitations

The reference model is finite and canonical, not a refined real material.
Python's event-resolved analysis and Unity's sampled-state presentation are
separate implementations. No bulk diffraction, material calibration,
exact-real certification, independent-user validation, sustained headset
performance, screen-reader support or store certification is claimed.
WSL2 validation is not a separate physical machine. Original benchmark timings
exclude enumeration, I/O, rendering and Unity.
