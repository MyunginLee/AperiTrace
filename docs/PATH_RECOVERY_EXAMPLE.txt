AperiTrace: change a path, recover a missed interval, recompute its diffraction

Run from an installed qc5d environment, using a new output directory:
  python -m qc5d.recover_interval --output changed-path
  python -m qc5d.exploration --recompute changed-path/inside.json

Equivalent repository entry point:
  python examples/softwarex_changed_path.py --output changed-path-other

Original path: (-0.61, 0.43) -> (0.67, -0.31)
Edited path:   (-0.60, 0.45) -> (0.66, -0.27)
Both use 33 evenly spaced parameters, 571 canonical candidates, unit weights,
and q=(1.6,0,0), (1.6,0,1), in dimensionless model units.

What the example actually does
1. Builds a new interval object for the edited path. Retains the same immutable
   physical-coordinate/q phase cache; it does not reuse stale path intervals.
2. Evaluates the sampled masks, then discovers fully interior positive-width
   intervals that contain no selected sampled state. No focus or midpoint is
   hard-coded into discovery. Diagnostic-sensitive midpoint witnesses are not
   presented as clear recoveries.
3. Chooses the first qualifying exact lattice identity in canonical row order.
   It exports the neighboring sampled states and the recovered interval midpoint.
4. recompute_state reconstructs coordinates from exact tuples, checks the direct
   finite-edge mask/status/count/IDs, and evaluates fresh finite sums. It does
   not reuse the path's cached amplitude or trust its serialized selected mask.

Observed default case
Two sites have missed intervals: (-1,1,0,0,-2) and (0,2,1,1,-1). Their nearly
coincident float64 roots are retained separately, not tolerance-merged.
For focus (-1,1,0,0,-2), seven original-path samples were selected. On the edited
path zero of the same 33 samples select it. Its new interval is approximately
(0.8222154361321617, 0.826024193676834), entirely in the sampled gap
[0.8125, 0.84375]. The midpoint is 0.8241198149044979.

State          lambda              focus   N     I(q=(1.6,0,0))
before         0.8125              OUT     123   0.02756640649983375
recovered      0.8241198149044979   IN      125   0.023176916443348905
after          0.84375             OUT     123   0.022199331222934743

The inside-minus-before intensity change is -0.004389490056484844 at the first
q and -0.002074294658145714 at the second. These are whole-selected-set results,
not an isolated-site attribution. Increased N need not increase finite intensity.
All three default states are clear_float64; this is not exact-real certification.
The original 33 sampled states are correct: they simply omit the excursion.

Output
summary.json records both paths, sampling, discovered IDs, bounds, identity,
three states, intensity differences and direct-recomputation errors.
before.json / inside.json / after.json are self-contained linked state exports.
Expected reference agreement is within absolute 1e-12 for F/max(1,N) and
normalized intensity. IDs/counts/status/shapes are exact. Tiny platform roundoff
may change last digits, not the stated float comparison budgets.

Try a different path
  python -m qc5d.recover_interval --start -0.55 0.4 --end 0.63 -0.28 --samples 9 --output edited-nine
  python -m qc5d.recover_interval --start 0 0 --end 0 0 --output stationary
Endpoints must stay within the bundled model's [-0.75,0.75]^2 domain.
Sample count is bounded to [2,4097]. A path without a clear missed interval
reports NO_CLEAR_MISSED_INTERVAL and writes only a summary, not a fabricated
positive recovery. Existing output directories are never overwritten.

Scope
This is an illustrative canonical software workflow, not a new material result
or a new benchmark population. The paper's existing benchmark numbers are not
replaced by these two example intervals. Unity is not required; its sampled-state
viewer is separate from Python's event-resolved path analysis.
